# XAUUSD CRT Bot V2 Research Workflow

## Objective

V2 research focuses on finding evidence-backed CRT rules for GOLD/XAUUSD using 1R and 1.5R outcomes instead of 2R/3R. The goal is to increase hit rate and make the strategy easier to validate before any demo automation is allowed.

## Current build status

- V1 MT5/XM demo connection: complete
- Demo-only safety lock: complete
- Broker symbol resolution: complete
- Completed-candle-only data: complete
- Signal journal and duplicate execution guard: complete
- Baseline backtester: complete
- CRT occurrence research dataset: complete
- Segmentation engine: complete
- V2 walk-forward candidate validation: in progress

## Important safety principle

No live trading is allowed in V1/V2. Execution remains locked to DEMO. The system should not be promoted to semi-auto or live until the rule has passed chronological validation, forward demo testing, and execution-cost modeling.

## Target focus

The V2 research target focus is:

- 1R
- 1.5R

2R and 3R are no longer the default research labels. They can still be generated by explicitly passing a custom ResearchConfig in code if legacy analysis is needed.

## Killzone focus

The current default New York killzones are:

- NY_08_10
- NY_09_11
- NY_10_12
- NY_11_13
- NY_08_13

These are implemented in `backtesting/killzones.py` and are used by the segmentation and walk-forward research layers.

## Main commands

Run tests:

```powershell
pytest -q
```

Build/rebuild the CRT occurrence dataset:

```powershell
python run_research.py --start 2023-01-01 --end 2026-09-01
```

Analyze 1R/1.5R segments:

```powershell
python analyze_research.py --dataset data\research\GOLD_crt_occurrences_2023-01-01_2026-09-01.csv
```

Run walk-forward validation for candidate V2 rules:

```powershell
python walk_forward_research.py --dataset data\research\GOLD_crt_occurrences_2023-01-01_2026-09-01.csv
```

## Data leakage rule

All features are frozen at H1 decision time. Only the outcome-label columns are allowed to use future bars.

This means the dataset is designed to be safe for chronological ML training later.

## Known data limitation

The user requested 2023-2026 data, but the available occurrence dataset currently starts on 2025-04-11. This means the current research set is about 16.5 months of usable CRT events rather than the full 3.7 years requested. Conclusions should therefore be treated as provisional until deeper history is obtained or out-of-sample forward demo testing confirms the edge.
